## Challenge ideas to pull from
- Build a network that survives a single link failure (redundancy/STP)
- Segment a "company" into VLANs with correct trunking, no manual IP misconfig
- Recreate a topology from a CCNA practice question and verify it behaves as described
- Break something on purpose, then troubleshoot without undo
