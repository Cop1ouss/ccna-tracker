## Domain order (suggested)

Study in blueprint-weight order so the highest-value domain gets the most
runway before test day:

1. **IP Connectivity (25%)** — start here, it's the biggest chunk of the exam
2. **Network Fundamentals (20%)** — foundational, needed to understand everything else
3. **Network Access (20%)** — VLANs/STP build directly on fundamentals
4. **Security Fundamentals (15%)**
5. **IP Services (10%)**
6. **Automation & Programmability (10%)** — newest content (AI/ML additions), do last so it's freshest for test day
